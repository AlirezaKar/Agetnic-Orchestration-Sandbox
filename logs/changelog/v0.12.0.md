# v0.12.0 — the studio redesign

- **Date:** 2026-11-01
- **State:** merged — PR #22, merge commit `42192f5`
- **Scope:** the page only — `app/static/index.html`,
  `app/static/assets/css/{styles,extra}.css`, `app/static/assets/js/app.js`,
  the two UI test scripts and the docs. No API, orchestrator, config, provider
  or log change; the server contract is byte-for-byte what 0.11.1 served.

## What this is

The interface was rebuilt on a supplied design. `docs/redesign/reference.html`
is the concept prototype, `docs/redesign/preview.png` the visual target; both
are committed so the look has a source of truth in the repo. The prototype is a
*static mock* — CDN `marked`/`DOMPurify`, hardcoded run data, a fake
`AGENT_API_CONFIG.send()`. The app keeps the look and wires it to the real API:
every number on screen still comes from `/health`, `/providers`, `/agents`,
`/runs`, `/sessions`, `/orchestrate`, `/chat`, `/search` or `/diagnose`.

## The frame

Same contract as 0.11.1, new class names:

```
body { overflow: hidden }
.app-shell   { height: 100%; display: flex; flex-direction: column }
.workspace   { flex: 1; display: grid; grid-template-columns: var(--sidebar-width) minmax(0, 1fr) var(--inspector-width); overflow: hidden }
.chat-scroll, .inspector, .inspector-content { min-height: 0 }
.sidebar      { overflow: auto }        /* its own list scrolls */
.chat-scroll  { flex: 1; overflow: auto }
.json-view    { flex: 1 1 auto; min-height: 0; overflow: auto }
```

The page never scrolls: the top bar stays, the three columns take the rest, and
a 20 000-line trace scrolls inside the inspector instead of stretching the row.
Below 980 px the inspector becomes a drawer that starts closed (so it can never
cover the chat on a tablet), below 700 px the sidebar does too, and `⌘/Ctrl + I`
toggles the inspector on any width.

### Markdown, offline

The prototype renders answers with `marked` + `DOMPurify` from a CDN. A sandbox
that cannot reach a CDN would answer in raw `###` and `|` — worse than before the
redesign. So `app.js` carries a small parser that builds **DOM nodes**, never
HTML strings:

```
# h1 … #### h4      | a | b |  + |---|  → table (wrapped for horizontal scroll)
``` code fences (with language + copy)   > quote → callout
- / * / 1. lists                          **bold**  *italic*  `code`  [text](url)  bare URLs
```

It is boundary-aware: `LLM_PROVIDER` stays literal, `_emphasis_` still works.

## Verify

```
python3 -m unittest discover -s tests -t .    →  439 tests OK
node tests/ui_smoke.js http://localhost:8000  →  all checks passed
node tests/ui_consent.js                      →  all checks passed
```

New checks in `ui_smoke.js`:

* **scenario F** stubs `/orchestrate` (the live server has no key) and asserts
  the answer surface really renders: `markdown-body`, `h2`, `strong`+`em`,
  `.table-wrap table.markdown-table`, two list items, `.callout`, a fenced
  `.code-block pre code`, inline `code` and a link, one source chip;
* the orchestration panel carries one chip per planned agent and **one trace row
  per event** (nothing is dropped by the prettier rendering);
* the inspector shows a run summary, a 3-item numbered timeline, a tool-activity
  card and >5 context rows; the `JSON` tab shows the payload and hides the other
  views, `Context` comes back;
* `Close inspector` adds `.inspector-collapsed` to `.workspace` and the toolbar
  toggle removes it;
* **scenario E** (frame) now reads `.app-shell`, `.workspace`, `.chat-scroll`,
  `.inspector`, `.json-view` and `.sidebar` through the cascade: the shell is
  `height: 100%`, the workspace clips and keeps `minmax(0, …)`, the chat and the
  inspector keep `min-height: 0px` and scroll, the JSON scrolls, and the sidebar
  is five `section`s (sessions, runs, agents, search + nav) with no prose.

New checks in `test_api.py`:

* `test_the_columns_scroll_inside_the_screen` describes the new frame
  (`.app-shell`, `.workspace`, `.chat-scroll`, `.inspector`, `.inspector-content`,
  `.json-view`, `.sidebar`, `.run-list`) instead of the retired `.layout`;
* `test_sidebar_is_one_tidy_column` keeps every earlier assertion (no
  `#btn-diag`, one Runs panel with two tabs, no explanatory paragraphs,
  `#diag-summary` inside `#inspector`) and only widens the inspector window from
  1200 to 2000 characters, because the inspector now carries a title row, a note
  and a tab strip before the diagnostics block.

**Honest limit:** there is no browser in this sandbox, so nothing here is a
pixel comparison with `preview.png`. The design system is the reference's CSS
(ported, not rewritten), the structure is asserted through jsdom, and the frame
is asserted through jsdom's cascade. The visual acceptance target is
`docs/redesign/preview.png`; open <http://localhost:8000> and compare.
